# 0038 — เมนูนำทางรวมเป็นแถวเดียวกับ header พร้อม mega menu สไตล์ Linear

Status: accepted and built.

## Context

เดิมเมนูบนเป็นแถวแยกใต้ header: รายการต่อโมดูล 11 รายการ + ปุ่มการตั้งค่า เมื่อโมดูลเพิ่มขึ้นต้องยุบเข้าเมนู
"เพิ่มเติม" (B1) และมีบั๊กตามมาหลายรอบ (N1/N2, dropdown ล้นขอบ) เจ้าของโปรเจกต์สั่ง redesign พร้อมภาพอ้างอิง
mega menu ของ Linear: "เอาแถบนี้ขึ้นไปไว้ข้างบน ปุ่มการตั้งค่าไม่ต้องแสดง และการแสดงให้รวมแอพไว้ที่เดียวเลย"

## Decision

- **แถวเดียว**: header = โลโก้ · หน้าแรก · ปุ่ม "เมนูใช้งาน" (mega menu) · ค้นหา/ธีม/ปรับแต่ง/กระดิ่ง/ภาษา/โปรไฟล์
  ไม่มีแถวเมนูแยกอีก header กว้างเต็มจอ (เนื้อหาหน้ายังคง `--page-max`)
- **Mega menu** (`layouts/MegaMenu.tsx`): trigger เดียวเปิดแผงคอลัมน์ 4 กลุ่ม — จัดซื้อ (ขออนุมัติจัดซื้อ,
  ขอราคา, ใบสั่งซื้อ — สามเอกสารของ flow เป็นแถวของตัวเอง), คลังและข้อมูลหลัก (WMS, MDM), วางแผนการผลิต
  (MRP, S&OP, APS), เครื่องมือ (บาร์โค้ด/QR, ภาพรวมระบบ, แอปพลิเคชันทั้งหมด → /apps ซึ่งยังเป็นที่เดียว
  ที่เห็นโมดูล "กำลังพัฒนา") · แต่ละรายการ = ไอคอน Octicon + ชื่อ + คำอธิบาย 1 บรรทัด จาก catalog/PR_PAGES
  ที่เป็น {th,en} อยู่แล้ว · แสดงเฉพาะโมดูลที่ผู้ใช้มีสิทธิ์ (canAccess + feature flag ผ่าน `useMyApps` เดิม)
  · trigger ขึ้น active เมื่อหน้าปัจจุบันเป็นปลายทางใดก็ตามในแผง
- **แหล่งข้อมูลเดียว**: `useNavGroups()` (`layouts/useNavItems.ts`) — mega menu, drawer มือถือ และ sidebar
  ดึงจาก hook เดียวกัน จะได้ไม่เห็นไม่ตรงกันอีก (guard test ตรึง)
- **การตั้งค่าออกจากเมนูนำทาง**: ใช้รายการเดิมในเมนูโปรไฟล์ (AccountMenu, Ctrl+,) · deep link `/settings/...`
  ไม่เปลี่ยน · drawer มือถือเพิ่มแถว "การตั้งค่า" ของตัวเอง (header มือถือมีแต่ avatar) · sidebar คงปุ่มใน footer
  (พื้นผิวประจำของโหมดนั้น การตัดออกไม่ได้อะไรและเสีย muscle memory)
- **Sidebar**: สะท้อนกลุ่มเดียวกันเป็นลิสต์แนวตั้ง — หัวข้อกลุ่มเมื่อกว้าง เส้นคั่นเมื่อเป็น rail (68px ไม่มีที่ให้คำ
  และไอคอนมี tooltip อยู่แล้ว) · เมนูย่อย PR แบบกาง/flyout เดิมถูกแทนด้วยแถวจัดซื้อ 3 แถว หน้า PR ที่เหลือ
  อยู่ในแท็บของโมดูลเอง
- **คุณภาพที่บังคับ** (บทเรียนจากบั๊กก่อนหน้า): แผง clamp เข้าขอบจอด้วย offset metrics (rect ของแผงโกหก
  ระหว่าง animation `pop`) และห้ามใช้ scrollWidth · Esc/คลิกนอก/เลือกแล้วปิด · โฟกัสเข้าแผง Tab วน ลูกศรเดิน
  รายการ โฟกัสคืน trigger (`useFocusTrap` ตัวเดียวกับ dialog) · drawer ยังเป็น modal ตาม D1

## Consequences

- โค้ดยุบรายการ (visibleCount/วัดล้น/เพิ่มเติม) หายทั้งก้อน — ที่มาของบั๊กสามรอบล่าสุด
- guided tour ไม่กระทบ (anchor ทั้งหมดอยู่บนหน้า/ปุ่มค้นหา ไม่มีบน nav เดิม)
- setting รูปแบบเมนู (top/side/rail/floating) ยังอยู่: top = แถวเดียวใหม่ · floating style ที่เคยลอยแถบเมนูแยก
  ไม่มีผลกับ top อีก (แถบหาย) — คงไว้กับ sidebar ตามเดิม
- guard tests: `NavOverflowGuardTests` ฉบับใหม่ตรึง clamp/no-scrollWidth, settings อยู่ใน AccountMenu,
  drawer เป็น modal + มีรายการตั้งค่า, และทุกพื้นผิวใช้ `useNavGroups`
