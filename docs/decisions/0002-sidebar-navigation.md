# 0002 — Sidebar navigation, collapsible groups, no top menu

Status: superseded by [0012](0012-top-navigation-and-tabler-style.md)

## Context
A launcher-style top menu was tried against the existing left menu.

## Decision
Keep the left sidebar and let groups collapse, as GitHub does. No top menu.

## Consequences
- Application groups have an accent colour used only on icons, dots and light backgrounds, never on text (contrast).
- Several applications open at once in tabs is parked.
